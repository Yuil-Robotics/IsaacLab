`-`는 읽기 실패(응답 bit23~16 = 01). hip_pitch 4개는 alveolous_open, iq_test, dcc_set이,
7·10번은 dcc_set이 안 읽힌다. 펌웨어 버전 차이로 보인다.
iq_ref, spd_ref, loc_ref, mechPos, mechVel, iqf는 명령·측정값이라 표에서 뺐다. JSON에 있다.

굵은 값은 같은 모델의 다른 모터와 다른 것.

- limit_torque, limit_cur: 12개 모두 공장 기본값. 소프트웨어 토크 상한 없음.
- 2026-09-15 변경·저장: 1번 limit_spd 20→10, loc_kp 20→60, spd_kp 5→6, spd_filt_gain 0.05→0.1.
  3번 vel_max, acc_set 0→10. 전원 재투입 후 유지 확인.
- iq_test: 1번만 0, 4·7·10번은 1. 의미 미확인이라 그대로 둠.
- canTimeout 20000 = 1 s. CAN 명령이 1 s 끊기면 모터가 Reset 모드로 간다.

MIT 모드에서 유효한 한계는 limit_torque뿐이다. limit_spd, limit_cur는 위치·속도 모드용.

## 읽기 · 쓰기 · 저장

호스트 0xFD, 모터 N. 값은 little-endian float (10.0 = `00002041`, 20.0 = `0000A041`).

| 동작 | 프레임 (모터 1, limit_spd 0x7017) | 응답 |
|---|---|---|
| 읽기 | `cansend can2 1100FD01#1770000000000000` | `110001FD`, 4~7바이트가 값. ID bit23~16이 01이면 실패 |
| 쓰기 | `cansend can2 1200FD01#1770000000002041` | 타입 0x02 피드백 |
| 저장 | `cansend can2 1600FD01#0102030405060708` | `000001FE` + MCU ID (device ID 프레임) |

0x70xx에 쓴 값은 전원을 끄면 사라진다. 저장(0x16)을 보내면 유지된다. 저장은 모터 설정 전체를
플래시에 쓰므로 바꿀 값만 쓴 뒤 보낸다. 앱은 끄고 모터는 정지 상태에서 한다.
0x20xx 저장용 표는 이 펌웨어에서 CAN 읽기가 실패한다.

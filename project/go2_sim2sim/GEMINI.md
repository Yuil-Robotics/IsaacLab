# Project Guidelines & Rules

## Text and Formula Formatting

- **수식 표기 시 LaTeX 달러 기호(`$` 및 `$$`) 사용 금지**
- 모든 수식, 변수, 단위, 수치는 LaTeX 문법 대신 **일반 텍스트와 기본 기호**(`=`, `≈`, `/`, `*`, `~` 등) 및 백틱(code span)만 사용하여 표기할 것.
- 예시:
  - 금지: `$f = 3.0\text{ Hz}$`, `$$T = \frac{1}{3.0} \approx 0.333\text{ 초}$$`
  - 권장: `f = 3.0 Hz`, `T = 1 / 3.0 ≈ 0.333 초 (333.3 ms)`
